# Analysis of Traffic Accidents in São Paulo

A project to analyze data on traffic accidents in the state of São Paulo. Public data on accidents, vehicles, and people involved between 2019 and 2024 were explored and processed to identify patterns, trends, and risk factors.

The notebooks included the steps of data cleaning (ETL) and visualization and analysis of the processed data.

## Technologies

- Python
- Pandas, Seaborn, Matplotlib, GeoPandas  
- Jupyter Notebook
